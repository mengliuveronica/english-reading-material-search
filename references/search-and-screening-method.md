# 检索、完整性核验与筛选方法

## 1. 将需求转成 search brief

至少明确以下字段；未知项写“未指定”和采用的假设：

| 维度 | 要回答的问题 |
|---|---|
| 学习者 | 年级、一般水平、班型或特殊需求是什么？ |
| 命题用途 | 阅读理解、完形、概要写作、语篇填空，还是主题拓展？ |
| 主题与角度 | 要解释、比较、叙事、问题解决，还是正反讨论？ |
| 长度 | 期望原文和改编后词数区间是什么？ |
| 文体 | 新闻、特写、科普、评论、研究解读、人物故事等有何偏好？ |
| 语言 | 可接受的术语、抽象度、长句与隐喻水平是什么？ |
| 背景知识 | 允许哪些地域、制度、文化或学科前置知识？ |
| 时效 | 截止日期、优先年份和常青例外是什么？ |
| 安全与再使用 | 敏感内容、开放许可、印刷或发布需求是什么？ |
| 多样性 | 是否需要不同观点、来源类型、地区或文体？ |

默认交付3–5篇来源可靠、适龄、彼此有区分度且原始页可完整公开访问的最终材料；不是3–5张候选卡。

## 2. 生成可调整的查询族

组合核心概念及自然英语近义表达、目标人群、文体/认知角度、证据形态与时间。首轮设计3–5个互补查询：至少覆盖一个广义主题、一个目标人群和一个证据/解释查询；争议议题增加反方或局限性查询。

来源保持开放。可在质量追踪阶段加入准确标题、独特短语、作者、研究机构或报告名，但不要预先锁死域名，也不要把搜索排名当质量判断。

## 3. 分轮搜索

### Round 1：发现生态

识别常见术语、原始发布者、代表性文体、转载簇、付费墙比例和噪声。搜索摘要只进入发现账本，不进入材料正文或事实字段。

### Round 2：质量与完整性驱动追踪

| 观察 | 调整动作 |
|---|---|
| 结果几乎全是聚合站 | 搜准确标题、独特短语、署名或被引机构，追到原始页 |
| 主题太窄 | 每次只放宽术语、人群、地域、年份或文体中的一个维度 |
| 多为付费墙/登录页 | 转向作者或机构公开原始版本、明确开放许可来源；不完整页淘汰 |
| 动态页面抓取不全 | 用普通浏览器复核首尾与展开状态；仍不能确认则淘汰 |
| 只有单一观点 | 搜 limitations、trade-offs、counterargument 或不同利益相关者 |
| 只有一个来源类型 | 补搜研究解读、新闻特写、机构说明或第一人称材料 |
| 同文多站转载 | 建来源簇，查首发/授权声明、作者页、DOI和规范URL |

### Round 3：填补明确缺口

只为补齐材料数量、文体/角度多样性、适龄短文或完整公开原始页继续搜索。2–3轮仍不足3篇时停止，报告缺口与可放宽项；不要用片段、转载拼接或低质来源凑数。

## 4. URL级核验账本

对每个实际打开页面记录：访问时间、查询来源、标题、作者、机构、日期状态、URL、来源关系、许可状态、访问控制、正文首尾/边界、保留或淘汰及理由。未打开的搜索结果只能记作发现线索。

完整性核验至少包括：

1. H1/文章标题可见；
2. 正文第一段与最后一段可见；
3. 所有小标题及其段落均正常加载；
4. 没有未展开的 `read more`、缺页、登录/订阅提示或明显截断；
5. `webfetch` 与普通浏览器差异已消解，或至少普通浏览器能可靠确认完整边界；
6. 不需要其他域名、搜索摘要或模型补写来补全。

任何一项不能确认，页面只能进入 `Discard log`，不能以 `uncertain` 进入 Material。

## 5. 提取与文本质检

对通过硬筛的页面提取 main body：

- 在JSON的 `original_text.blocks` 中，第一块使用 `type: title` 保存原始标题，其后以 `subtitle`、`heading`、`paragraph`、`list_item` 保留副标题、小标题、段落、必要列表及其顺序；
- 只删除导航、广告、cookie提示、分享按钮、推荐链接等 chrome；
- 不翻译、改写、纠错、重排、合并段落或标准化英美拼写；
- 不把图片说明、表格或脚注无声删除；若其对论证必要且无法可靠转成文本，淘汰页面；
- 不把网页UI、教学提示、入选理由、风险或模型说明混进 `original_text.blocks`；
- 用JSON校验器的英文词元规则计算所有原文 blocks 的词数（标题和小标题计入），把精确数字写入 `teaching_fit.word_count`。

提取后对照页面再次检查标题、首段、小标题序列和末段。任何截断迹象都使该页回到 Discard log。

## 6. 两阶段筛选

### A. 硬筛

以下任一情况即淘汰：

- 出处不可追溯、疑似未标注采集或实质重复；
- 正文不完整、登录/付费墙截断、动态失败后完整性不明；
- 需要从摘要、缓存、镜像或其他转载页补齐；
- 标题、作者状态、机构、日期状态、URL等关键元数据不足；
- 内容明显过时且无常青价值，或敏感内容无法小幅处理；
- 为达到教学目标必须重写关键论证、拼接多篇或改变作者立场。

### B. 相对评估

用低/中/高或明确适龄结论，并紧跟可检查依据：

- **主题匹配**：中心问题是否符合教师意图，而非只含关键词。
- **词数**：统计 `original_text.blocks` 中的英文词元，含标题/副标题/小标题，不含提取说明和网页 chrome。
- **语言负荷**：低频/学术词、术语、句长/嵌套、衔接、习语和抽象度。
- **背景知识负荷**：制度、地域、历史、文化、人物和学科前置知识；区分一句脚注可解决与贯穿全文。
- **适龄性**：认知可及性、生活关联、情绪/安全风险、刻板印象和争议处理。
- **改编负荷**：低为少量删节/释义；中为多处删节或少量补充背景；高为重排、大量去情境化或改写关键论证。

高改编负荷或贯穿性风险通常不进入最终包。无法确保删改后保持原意时直接淘汰。

## 7. 形成最终组合与停止条件

最终保留3–5篇非重复 Material，优先具备至少两种文体/证据形态、不同角度、合理长度梯度，并在质量达标后兼顾地区/机构多样性。

可以停止的条件：

- 3–5个原始页均逐URL核验且完整公开可访问；
- 每篇 main-body extraction 已对照标题、首段、小标题和末段；
- 元数据、许可状态、教学负荷和风险均已记录；
- 至少一次检查反方/局限或来源多样性；
- 查询调整与淘汰原因可追溯。

若不满足数量或完整性要求，只交付诚实的检索缺口说明和 Discard log，不把它称为通过校验的 English Reading Material Pack。让教师选择放宽地域、年份、相邻主题、长度或文体，不擅自放宽完整访问要求。
