# 教师请求示例

## 可以直接这样说

> 请为高二英语阅读理解课寻找3篇关于“青少年参与社区问题解决”的英文材料。每篇原文控制在500至800词，以说明文或新闻特写为主。材料应适合中国高中生，背景知识负担不要太高，并尽量来自大学、公共机构、主流媒体或专业组织的公开网页。

## Skill 会怎样处理

1. 根据年级、主题、篇幅和文体要求设计检索词。
2. 打开候选网页，核对作者、发布机构、日期、正文是否完整以及来源关系。
3. 保留完整英文原文，计算词数，并判断语言负荷、背景知识、适龄性和改编难度。
4. 分析课标词汇覆盖率，列出必修、选择性必修和未直接收录的关注词汇。
5. 比较候选材料，选择3–5篇内容不同、来源清楚、适合教学的文章。

## 教师会收到什么

- 一份可离线浏览的阅读材料包，可以逐篇查看并一键复制全文；
- 一份Word分析报告，汇总来源、教学适配、词汇覆盖、风险和使用建议；
- 每篇文章各自独立的纯文本文件，便于继续改编、命题或分析。

如果词汇服务在当前网络下暂时不可用，Skill会先说明情况。教师可以配置其他兼容服务，也可以确认先生成基础材料包，稍后再补充词汇覆盖分析。
